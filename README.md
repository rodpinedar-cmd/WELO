# WELO — La app para parejas

Retos diarios, juegos y preguntas diseñados para conectar con tu pareja en solo 2 minutos al día.

**[Abrir WELO →](https://rodpinedar-cmd.github.io/WELO/)**

## ¿Qué es WELO?

WELO es una Progressive Web App (PWA) gratuita para parejas que convierte la conexión en un hábito diario a través de:

- 🎯 **Reto diario** — micro-retos de conexión con misiones
- 💕 **Match Diario** — 5 preguntas para descubrir en qué coincidís
- 🎮 **Juegos** — Swipe pelis, Verdad o Reto, 36 Preguntas, y más
- ✨ **Planes** — actividades personalizadas por mood
- 🪲 **Lumi** — mascota tamagotchi que crece con la relación
- 🔥 **XP, streaks y badges** — gamificación para mantener el hábito
- 😊 **Mood Sync** — registro de ánimo con dot de pareja

## Stack

| Tecnología | Uso |
|---|---|
| HTML/CSS/JS | Frontend (vanilla, sin frameworks) |
| GitHub Pages | Hosting |
| Supabase | Auth + base de datos (EU) |
| PostHog | Analytics con consentimiento GDPR (EU) |
| PWA | Service Worker + manifest para instalación |

## Privacidad
